# Beecrowd 1117 - Validação de Nota

## Descrição
Programa desenvolvido em Java para ler duas notas de um aluno, validar os valores informados e calcular a média semestral.

## Linguagem
Java

## Entrada
O programa recebe valores reais correspondentes às notas do aluno. Cada nota deve estar no intervalo de 0 a 10.

## Saída
Imprime "nota invalida" para cada nota fora do intervalo permitido. Quando duas notas válidas forem informadas, imprime a média com duas casas decimais.
